# Plataforma de Gestión Humana

Plataforma web para la gestión integral de procesos de Gestión Humana y ciclo laboral.

## Tecnologías

- JavaScript
- React
- Vite
- Tailwind CSS
- Node.js
- Express.js
- PostgreSQL

## Módulos principales

La plataforma contempla diferentes módulos para apoyar el ciclo laboral:

- Gestión de vacantes
- Solicitudes de personal
- Registro y gestión de candidatos
- Procesos de selección
- Gestión documental
- Contratación
- Afiliaciones
- Cursos y requisitos laborales
- Autogestión del empleado
- Solicitudes de empleados
- Gestión de usuarios y roles
- Reportes
